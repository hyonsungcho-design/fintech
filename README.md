# fintech

국내 카드사·간편결제사 뉴스를 모아 웹 페이지로 보여주는 Claude Code 스킬입니다.

## card-payment-news

국내 카드사 9곳과 간편결제사 3곳의 **최근 1개월 기사**를 국내 언론사에서 회사별로 **최대 30건**씩 모읍니다. 결과는 게재일·언론사·요약이 붙은 웹 페이지(Claude Artifact)로 게시됩니다.

| 구분 | 대상 |
|---|---|
| 카드사 (9) | 삼성카드, 신한카드, KB국민카드, 롯데카드, 우리카드, 하나카드, BC카드, NH농협카드, 현대카드 |
| 간편결제사 (3) | 네이버페이, 카카오페이, 토스페이 |

### 결과 페이지

- 상단에 수집 기간, 기준일, 총 기사 수, 핵심 이슈 3~5개가 나옵니다.
- 회사 버튼마다 수집 건수(`12/30` 등)가 표시됩니다.
- 회사를 고르면 한 달 동향 요약과 기사 목록이 최신순으로 나옵니다.
- 기사마다 게재일, 언론사, 제목(원문 링크), 1~2줄 요약, 중요도, 카테고리가 붙습니다.
- 카테고리 필터(실적·재무, 규제·정책, 상품·서비스 등 8개)가 있습니다.
- **현시점 조회하기** 버튼을 누르면 페이지가 직접 최근 1개월 기사를 다시 모아 데이터를 갱신하고 저장합니다.
- 휴대폰 화면과 다크 모드를 지원합니다.

### 현시점 조회하기 버튼

1. 기준일을 오늘(KST)로 바꾸고 기간을 최근 1개월로 다시 잡습니다.
2. Claude 데스크톱 앱의 내장 브라우저로 회사별 Google 뉴스 RSS를 읽습니다.
3. 언론사 50곳의 기간 내 기사만 남기고, Claude로 같은 사건 기사를 묶고 카테고리·중요도·동향 요약을 정합니다.
4. 기존 기사와 합쳐 회사별 최대 30건으로 정리한 뒤 페이지를 새 버전으로 저장합니다.

- Claude **데스크톱 앱**에서 페이지를 열었을 때만 동작합니다. 웹 브라우저에서는 버튼을 눌러도 안내 문구만 나옵니다.
- 처음 누를 때 브라우저 사용과 Claude 사용을 허용하는 확인 창이 뜹니다. Claude 사용분은 누른 사람의 사용량에서 차감됩니다.
- 버튼으로 모은 기사에는 '자동 수집' 표시가 붙고, 요약은 없으며, 링크는 Google 뉴스 주소입니다.
- 저장 권한이 없는 사람이 누르면 그 화면에만 반영됩니다.

## 사용법

Claude Code에서 아래처럼 요청합니다.

```
/card-payment-news
```

자연어 요청도 됩니다.

- "이번 달 카드사 뉴스 정리해줘"
- "토스페이랑 카카오페이 최근 소식"
- "카드사 실적 기사만 모아줘"

기간·건수·대상·주제를 따로 말하지 않으면 최근 1개월, 회사별 최대 30건, 12개사 전체를 기본값으로 씁니다.

| 섹션 | 내용 |

| Guardrail | 사실 날조·채우기 금지, 투자 조언·카드 추천 금지, 루머 단정 금지, 안전한 렌더링 등 |

## 검색 대상 언론사

종합일간지·통신·방송·경제지·IT·금융 전문지 50곳을 대상으로 합니다. 목록은 [outlets.md](.claude/skills/card-payment-news/references/outlets.md)에 있습니다.

이 중 8곳(매일경제, 조선일보, 중앙일보, 동아일보, 한겨레, KBS, 연합뉴스, 연합인포맥스)은 Claude의 웹 검색 도구가 접근을 막고 있어 검색 범위에서 뺍니다. 실제 검색은 나머지 42곳을 4개 그룹으로 나눠 합니다.

## 한계

- 검색 도구가 국내 기사를 충분히 잡지 못해, 회사에 따라 30건을 채우지 못할 수 있습니다. 부족하면 찾은 만큼만 싣고 이유를 보고합니다.
- 게재일을 확인하지 못한 기사, 목록 밖 매체, 블로그·이벤트 페이지는 싣지 않습니다.
- 요약은 기사를 재서술한 것입니다. 수치와 세부 내용은 원문에서 확인하세요.
- 투자 판단의 근거로 쓰지 마세요.
