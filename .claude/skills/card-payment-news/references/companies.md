# 기업별 검색 키워드

검색 시 기본 키워드로 먼저 찾고, 결과가 적으면 동의어/관련 키워드를 추가한다.
동음이의 오탐(예: "현대카드" 검색 시 현대차 일반 기사)은 Step 2에서 제외한다.

## 카드사

| 기업 | 기본 키워드 | 동의어·관련 키워드 | 자주 나오는 이슈 |
|---|---|---|---|
| 삼성카드 | 삼성카드 | 삼성카드 실적, 삼성카드 김이태 | 실적, 데이터 사업, 삼성페이 연계 |
| 신한카드 | 신한카드 | 신한 SOL페이, 신한카드 PLCC | 업계 1위 실적, AI·플랫폼, 조직개편 |
| KB국민카드 | KB국민카드 | 국민카드, KB Pay | 실적, KB Pay, 해외 법인 |
| 롯데카드 | 롯데카드 | 롯데카드 매각, 롯데카드 MBK, 로카 | 매각 진행, 정보보호·보안 이슈 |
| 우리카드 | 우리카드 | 우리카드 독자가맹점, 우리WON카드 | 독자결제망, 지주 내 역할 |
| 하나카드 | 하나카드 | 트래블로그, 하나카드 해외 | 트래블로그·해외결제, 실적 |
| BC카드 | BC카드 | 비씨카드, BC카드 KT, 페이북 | 결제 프로세싱, 자체카드, 해외 결제망 |
| NH농협카드 | NH농협카드 | 농협카드, NH페이 | 농협금융 실적, 전산 이슈 |
| 현대카드 | 현대카드 | 현대카드 애플페이, 현대카드 PLCC, 현대카드 정태영 | 애플페이, PLCC, 데이터·AI |

| 기업 | 기본 키워드 | 동의어·관련 키워드 | 자주 나오는 이슈 |
|---|---|---|---|
| 네이버페이 | 네이버페이 | 네이버파이낸셜, 네이버페이 오프라인 | 오프라인 결제, 거래액, 두나무 등 제휴·지배구조 |

## 업계 공통 검색어

- 카드업계 가맹점 수수료
- 카드사 연체율 / 카드론 잔액
- 여신금융협회 / 여전채 금리
- 간편결제 규제 금융위원회 / 전자금융거래법
- 오프라인 간편결제 경쟁
- 애플페이 국내 카드사 확대
